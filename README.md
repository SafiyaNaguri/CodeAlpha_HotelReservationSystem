# CodeAlpha_HotelReservationSystem
# 🏨 Hotel Reservation System

A Java-based **Hotel Reservation System** developed as part of the **CodeAlpha Java Programming Internship**. This project demonstrates Object-Oriented Programming (OOP) concepts by allowing users to search rooms, make reservations, cancel bookings, simulate payments, and manage hotel booking records through a menu-driven console application.

---

## 📌 Features

- 🛏️ View available hotel rooms
- 🔍 Search rooms by category
- 📅 Book hotel rooms
- ❌ Cancel reservations
- 💳 Simulate payment process
- 📋 View booking details
- 🏨 Multiple room categories
- 📂 Menu-driven console interface
- 💾 Booking records stored using file handling
- ✅ Input validation for better user experience

---

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- File Handling

## 🚀 How to Run

### Clone the Repository

```bash
git clone https://github.com/SafiyaNaguri/CodeAlpha_HotelReservationSystem.git
```

### Open Project

```bash
cd CodeAlpha_HotelReservationSystem
```

### Compile

```bash
javac *.java
```

### Run

```bash
java Main
```
